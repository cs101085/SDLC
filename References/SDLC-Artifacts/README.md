# SDLC-Artifacts

Persist and manage artifacts generated by SDLC workflows.

## Purpose

This repository is a central storage location for artifacts generated by SDLC workflows that run in dedicated repositories.

Each workflow execution can be associated with a Jira ticket and is stored in a deterministic folder structure.

## Directory Convention

Artifacts are stored under:

`Artifacts/<JIRA_ID>/<YYYYMMDD_HH24MISS>/`

Example for June 19, 2026 at 16:43:00:

`Artifacts/SDLC-123/20260619_164300/`

Each execution directory must contain a `manifest.json` file.

See `Artifacts/README.md` for manifest details and evolution guidance.

## Workflow: Prepare Execution Directory

The reusable workflow in `.github/workflows/prepare-execution-directory.yml` prepares an execution folder and ensures a manifest exists.

Inputs:

- `jira_id` (optional)
- `artifact_path` (optional)

Rules:

- At least one input must be provided.
- If only `jira_id` is provided:
  - Generate `currdate_string` in `YYYYMMDD_HH24MISS` format.
  - Resolve `artifact_path` as `<jira_id>/<currdate_string>`.
- Ensure `Artifacts/<artifact_path>/` exists.
- Ensure `manifest.json` exists in that directory.
- Return absolute `manifest_path` output.

### Example (same repository)

```yaml
jobs:
  prepare:
    uses: ./.github/workflows/prepare-execution-directory.yml
    with:
      jira_id: SDLC-456

  publish:
    needs: prepare
    runs-on: ubuntu-latest
    steps:
      - run: echo "Manifest is at ${{ needs.prepare.outputs.manifest_path }}"
```

`prepare-execution-directory.yml` is intended as an internal helper workflow in this repository.

## Workflow: Prepare Artifacts

The reusable workflow in `.github/workflows/prepare-artifacts.yml` prepares an execution directory and manifest, but does not commit or push changes.

Persistence is handled only by `.github/workflows/persist-artifacts.yml`.

Inputs:

- `jira_id` (optional)
- `artifact_path` (optional)

Outputs:

- `currdate_string`
- `artifact_path`
- `manifest_path`

### Example (same repository)

```yaml
jobs:
  prepare-artifacts:
    uses: ./.github/workflows/prepare-artifacts.yml
    with:
      jira_id: SDLC-789

  persist-artifacts:
    needs: prepare-artifacts
    uses: ./.github/workflows/persist-artifacts.yml
    with:
      artifact_path: ${{ needs.prepare-artifacts.outputs.artifact_path }}
      commit_message: "My Commit Message"
```

## Workflow: Persist Artifacts

The reusable workflow in `.github/workflows/persist-artifacts.yml` commits and pushes artifact changes under `Artifacts/`.

Inputs:

- `artifact_path` (optional)
- `commit_message` (optional, default: `chore(artifacts): persist workflow artifacts`)
- `artifact_bundle_name` (optional; uploaded workflow artifact name to download before commit)

Outputs:

- `changed`
- `commit_sha`

### Example (same repository)

```yaml
jobs:
  persist-artifacts:
    uses: ./.github/workflows/persist-artifacts.yml
    with:
      artifact_path: SDLC-789/20260619_164300
      artifact_bundle_name: generated-artifacts
      commit_message: "My Commit Message"

  consume-output:
    needs: persist-artifacts
    runs-on: ubuntu-latest
    steps:
      - run: echo "Changed=${{ needs.persist-artifacts.outputs.changed }}"
      - run: echo "Commit=${{ needs.persist-artifacts.outputs.commit_sha }}"
```

## Split Workflow Pattern: Prepare, Generate, Persist

Use this pattern when you want clear separation between path preparation and commit/push behavior.

```yaml
name: Split Example Prepare Generate Persist

on:
  workflow_dispatch:
    inputs:
      jira_id:
        required: true
        type: string

jobs:
  # Prepare phase: resolve artifact_path and ensure manifest exists.
  prepare:
    uses: ./.github/workflows/prepare-execution-directory.yml
    with:
      jira_id: ${{ inputs.jira_id }}

  # Generate phase: create or copy artifact files into Artifacts/<artifact_path>/.
  generate:
    needs: prepare
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Create example artifact
        shell: bash
        run: |
          set -euo pipefail
          target_dir="Artifacts/${{ needs.prepare.outputs.artifact_path }}"
          mkdir -p "$target_dir"
          echo "Example artifact generated by split workflow" > "$target_dir/example-output.txt"

      - name: Upload artifacts for persist job
        uses: actions/upload-artifact@v4
        with:
          name: generated-artifacts
          path: Artifacts/${{ needs.prepare.outputs.artifact_path }}

  # Persist phase: download generated content, then commit and push changes.
  persist:
    needs: [prepare, generate]
    uses: ./.github/workflows/persist-artifacts.yml
    with:
      artifact_path: ${{ needs.prepare.outputs.artifact_path }}
      artifact_bundle_name: generated-artifacts
      commit_message: "My Commit Message"
```
